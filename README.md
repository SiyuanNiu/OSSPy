# OSSPy
This study develops an operator-splitting based PHREEQC–Python coupling framework (OSPPy), in which electrokinetic processes, solute transport, and equilibrium and kinetically controlled reactions are decomposed into sequential computational substeps and coordinated externally through Python. And OSPPy is presented with three benchmark cases: CK, a cation-exchange model; ISL, a CO₂–O₂ in situ uranium leaching model; and EK-ISL, an electrokinetically enhanced CO₂–O₂ in situ uranium leaching model.
