# OSSPy

OSPPy is an operator-splitting PHREEQC–Python framework for coupling electrokinetic processes, solute transport, and geochemical reactions in porous media. It addresses the limitation of PHREEQC in simulating electrokinetics and reactive transport within a single model. The overall workflow of the OSPPy framework is illustrated in Fig. 1.
<img width="12318" height="6929" alt="Fig  1" src="https://github.com/user-attachments/assets/a5811e37-67a7-4746-9c8d-281294d2cdf2" />

The framework is demonstrated through three benchmark cases:
- CK: Cation exchange
- ISL: CO₂–O₂ in situ uranium leaching
- EK-ISL: Electrokinetically enhanced CO₂–O₂ in situ uranium leaching.

The code is available in this repository. Experimental data are confidential and cannot be shared.
